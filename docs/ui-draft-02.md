# Space UI draft 02 — design context

The user selected A's workspace sidebar and home, B's header and kanban,
C's docked task inspector, and E's calendar. The sidebar must collapse, search
must remain visible with a shortcut, drag and drop must support status and
ordering, and task details must consume board width without a task modal.
A bottom connection/shortcut bar and adjustable theme/accent/layout are required.

Draft 02 explores that combination in six screens of one application.
The original A–E alternatives remain preserved. This draft awaits further user
feedback; it is not approved production UI. The native MyGo foundation remains
in app/ and internal/appui/. Prototype HTML must not replace those native views.
